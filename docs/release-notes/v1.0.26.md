## SKZ Connect 1.0.26

Controller für Windows-Spiele und Emulatoren, ergänzt durch eine Android-App und ein Kodi-/LibreELEC-Add-on für Switch-2-Controller.

| Plattform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.26.exe` · `SKZ-Connect-Portable-1.0.26.zip` |
| Android 8+, Beta 0.9.5 | `SKZ-Connect-Android-0.9.5.apk` |
| Kodi / LibreELEC 0.4.10 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs für x86_64, ARM64, ARM und alle Geräte |

Belegung, Gyro und Profile je Spiel. Modellbilder, eine reine Tastenansicht und 14 Farbschemata einschließlich **JoCo**. Geräteumfang und Funktionen unterscheiden sich je Plattform; Android bleibt eine Beta. Die neuen Android-/Kodi-Ansichten sind noch nicht auf echten Geräten visuell geprüft. Windows-App und Setup sind nicht code-signiert.

## SKZ Connect 1.0.26

Controllers for Windows games and emulators, with an Android app and a Kodi/LibreELEC add-on for Switch 2 controllers.

| Platform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.26.exe` · `SKZ-Connect-Portable-1.0.26.zip` |
| Android 8+, beta 0.9.5 | `SKZ-Connect-Android-0.9.5.apk` |
| Kodi / LibreELEC 0.4.10 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs for x86_64, ARM64, ARM and all devices |

Remapping, gyro and per-game profiles. Model artwork, a buttons-only view and 14 color schemes including **JoCo**. Device support and features differ by platform; Android remains in beta. The new Android/Kodi views have not been visually tested on real devices. Windows app and setup are not code-signed.
