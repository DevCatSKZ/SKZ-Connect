## SKZ Connect 1.0.28

Controller für Windows-Spiele und Emulatoren, ergänzt durch eine Android-App und ein Kodi-/LibreELEC-Add-on für Switch-2-Controller.

| Plattform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.28.exe` · `SKZ-Connect-Portable-1.0.28.zip` |
| Android 8+, Beta 0.9.6 | `SKZ-Connect-Android-0.9.6.apk` |
| Kodi / LibreELEC 0.4.11 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs für x86_64, ARM64, ARM und alle Geräte |
| Linux / SteamOS 0.4.11 | `SKZ-Connect-Linux-0.4.11-x86_64.tar.gz` |

Belegung, Gyro und Profile je Spiel. Modellbilder, eine reine Tastenansicht und 14 Farbschemata einschließlich **JoCo**. Geräteumfang und Funktionen unterscheiden sich je Plattform; Android bleibt eine Beta. Die neuen Android-/Kodi-Ansichten sind noch nicht auf echten Geräten visuell geprüft. Windows-App und Setup sind nicht code-signiert.

**Neu (Windows):** Lizenzierte Bluetooth-Controller werden erkannt und laufen wie ein Switch Pro Controller – etwa der PowerA „Enhanced Wireless Controller“, der sich als „Lic Pro Controller“ meldet (VID/PID 0000:0000). Diese Geräte haben keinen NFC-Leser und meist keine Vibration; die App blendet amiibo-Lesen für sie nicht ein.

**Neu (Linux):** Ein Paket für SteamOS bringt den SKZ-Connect-Dienst als systemd-Unit mit Installations- und Deinstallationsskript; die Anleitung liegt unter `docs/anleitung/steamos.md`. Auf echter SteamOS-Hardware noch ungetestet.

## SKZ Connect 1.0.28

Controllers for Windows games and emulators, with an Android app and a Kodi/LibreELEC add-on for Switch 2 controllers.

| Platform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.28.exe` · `SKZ-Connect-Portable-1.0.28.zip` |
| Android 8+, beta 0.9.6 | `SKZ-Connect-Android-0.9.6.apk` |
| Kodi / LibreELEC 0.4.11 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs for x86_64, ARM64, ARM and all devices |
| Linux / SteamOS 0.4.11 | `SKZ-Connect-Linux-0.4.11-x86_64.tar.gz` |

Remapping, gyro and per-game profiles. Model artwork, a buttons-only view and 14 color schemes including **JoCo**. Device support and features differ by platform; Android remains in beta. The new Android/Kodi views have not been visually tested on real devices. Windows app and setup are not code-signed.

**New (Windows):** Licensed Bluetooth controllers are recognized and work like a Switch Pro Controller – such as the PowerA “Enhanced Wireless Controller”, which identifies as “Lic Pro Controller” (VID/PID 0000:0000). These devices have no NFC reader and usually no rumble; the app does not offer amiibo reading for them.

**New (Linux):** A SteamOS package provides the SKZ Connect service as a systemd unit with install and uninstall scripts; the guide is at `docs/guide/steamos.md`. Not yet tested on real SteamOS hardware.
