## SKZ Connect 1.0.25

Neue Controllerdarstellungen und ein abgestimmtes Design für Windows, Android und Kodi.

| Plattform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.25.exe` · `SKZ-Connect-Portable-1.0.25.zip` |
| Android 8+, Beta 0.9.4 | `SKZ-Connect-Android-0.9.4.apk` |
| Kodi / LibreELEC 0.4.9 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs für x86_64, ARM64, ARM und alle Geräte |

- **Windows:** 28 neue Controllerbilder, korrigierte GameCube-Schultermarkierungen und eine dauerhaft umschaltbare reine Tastenansicht.
- **Design:** 14 abgestimmte Farbschemata mit überarbeiteten Buttons, Glasflächen, Rahmen und lesbaren Spielernummern.
- **Android 0.9.4:** passende Modellbilder in den Controllerkarten, abschaltbare Bildanzeige und gemeinsame Themefarben für Buttons und Karten. Die Live-Eingaben stehen unter dem Modellbild.
- **Kodi 0.4.9:** neue Modell- und Offline-Icons, getrennte Joy-Con-Generationen sowie Pro- und PlayStation-Modelle. Status-Plugin 1.1.5 und Bundle 1.0.7 verwenden denselben Bestand.
- **Dokumentation:** kompakte Beschreibungen, aktuelle Demoaufnahmen und bereinigte öffentliche Entwicklerunterlagen.

Windows-GUI, Builds und automatisierte Tests geprüft. Die neuen Android-/Kodi-Ansichten sind noch nicht auf echten Geräten visuell geprüft. Neue Bilder erweitern nicht die unterstützten Gerätetypen. Windows-App und Setup sind nicht code-signiert; Android bleibt eine Beta.

## SKZ Connect 1.0.25

Updated controller artwork and a consistent design for Windows, Android and Kodi.

| Platform | Download |
|---|---|
| Windows 10 / 11, x64 | `SKZ-Connect-Setup-1.0.25.exe` · `SKZ-Connect-Portable-1.0.25.zip` |
| Android 8+, beta 0.9.4 | `SKZ-Connect-Android-0.9.4.apk` |
| Kodi / LibreELEC 0.4.9 | [DevCatSKZ Repository](https://github.com/DevCatSKZ/kodi-repo) · ZIPs for x86_64, ARM64, ARM and all devices |

- **Windows:** 28 new controller images, corrected GameCube shoulder highlights and a persistent buttons-only display option.
- **Design:** 14 coordinated color schemes with updated buttons, glass surfaces, borders and readable player badges.
- **Android 0.9.4:** model images on controller cards, optional image display and shared theme colors for buttons and cards. Live input remains below the model image.
- **Kodi 0.4.9:** new model-specific and offline icons, separate Joy-Con generations, Pro and PlayStation models. Status plugin 1.1.5 and bundle 1.0.7 share the same artwork.
- **Documentation:** concise descriptions, current demo screenshots and cleaned public developer documentation.

Windows GUI, builds and automated tests checked. The new Android/Kodi views have not been visually tested on real devices. New artwork does not extend device support. Windows app and setup are not code-signed; Android remains in beta.
